# 拾光漫游 · DAYTRIP

用一天时间，发现城市里的小美好。

面向大学生与年轻人的一日微旅行网页 UI 原型。采用奶油白、森林绿与暖橙色，以旅行摄影、编辑式排版、主题卡片和行程时间轴，完成「选择偏好 → 发现路线 → 浏览行程 → 收藏纪念卡」的演示闭环。

当前交付版本：**1.1**。本轮从开发基线 1.0 递增一次，完成五页 UI、三条独立路线、交互闭环及浏览器验收。

## 技术与启动

HTML5、CSS3、原生 JavaScript，无框架、无安装步骤、无构建步骤。

**直接双击 `index.html` 即可演示**；也可用 VS Code Live Server 打开。

若已安装 Node.js，可在本目录运行：

```powershell
node tools/serve.js
```

随后打开 `http://127.0.0.1:4173`。按 `Ctrl+C` 停止预览。

也可使用 Python：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

所有页面、脚本、图标与摄影均使用本地相对路径，运行时不依赖外网。需要启用浏览器 JavaScript。

## 如何演示

1. 打开首页，点击「开启我的微旅行」。
2. 选择自然治愈、城市漫游或美食探索；一日漫游默认选中。
3. 点击「为我推荐路线」，选中主题的路线会排在首位并显示推荐标识。
4. 点击「查看行程」，查看该路线对应的六个时间节点。
5. 点击「完成今日旅行，领取纪念卡」，查看相同路线的纪念卡与浏览器当前日期。
6. 点击「再次探索」或「返回首页」，完成演示闭环。

路线列表还支持按主题筛选；导航、返回按钮、关于我们锚点均可操作。风格卡片使用原生单选控件，可用 Tab 与方向键操作；手机端提供折叠菜单，可用 Escape 关闭。支持 `prefers-reduced-motion`，并为图片异常设置渐变背景降级。

URL 示例：`detail.html?route=jianghan`。三个路线 ID 为 `donghu`、`jianghan`、`wuhan-food`。缺失或无效参数回退到默认内容；纪念卡按路线 ID 获取可信标题，不直接插入 URL 中的任意文本。

## 演示范围

这是**静态课程 UI 原型**，不是实际旅游服务。三条路线各自有完整的一日行程；半日选项用于偏好展示，仍提供明确标注的一日示例。推荐指数为演示数值；时间、活动安排、出行建议不代表实时交通或营业承诺。路线示意图不是实际地图，完成页是模拟状态。

首页山湖与森林照片为旅行氛围图；路线主图分别使用武汉东湖、江汉路和武汉热干面摄影。作者与许可见 [assets/CREDITS.md](assets/CREDITS.md)。

运行 `node tools/check.js` 可复查本地文件、三套行程、脚本语法与图片完整性。实际浏览器验收结果见 [TEST_REPORT.md](TEST_REPORT.md)，截图与原始检查记录位于 `qa/`。
