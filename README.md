# 拾光微旅 · DAYTRIP

**每座城，日夜都有新发现。当前版本：1.7（1.6 → 1.7，本轮统一递增一次）。**

面向各地区用户的微旅行课程原型。全国发现首页、城市与行程、个人跨城足迹构成三个层级；保留绿色、奶油白与夜间深蓝暖金皮肤，现有十二城、36条路线和108套时段行程保持可用。

## 1.7 首页轮播日夜联动

- 北京、杭州、重庆各有日间和夜间两套完整故事。外观开关同时替换三张图片、标题、介绍、地点说明、图片替代文字及按钮入口，包括未显示的轮播页。
- 日光模式对应颐和园日间、西湖一日、解放碑日间；夜色模式对应前门街区夜游、西湖湖岸夜游、洪崖洞夜游，入口带入各自的城市、兴趣与时段。
- 读取保存的外观、首次进入和手动切换采用同一联动逻辑；保留当前轮播位置、暂停状态与键盘焦点。首屏后空闲预加载另一组图片，失败时使用原占位样式。
- 原有旅行时段、住宿、足迹及全国精选入口保持各自的数据规则。摄影沿用已有本地授权素材，发布继续使用原 GitHub Pages 地址。

## 全国发现与个人足迹（1.6 起）

- 首页固定为全国视角，不推断所在地，不默认选中武汉。三城主视觉各有日夜两套故事，入口明确绑定城市、兴趣与时段。
- 全国精选首屏覆盖六个地区，展开后十二城各一项；展示推荐理由与时段，不显示全国名次或模拟热度。选择城市后可查看该城的五个代表景点与教学示例好评、探索者榜。
- 城市榜由人工配置，不再使用行程列表前五项，排除入口、休息点和返程站。精选与榜单入口绑定相关路线和时段，避免园林景点链接进入另一条夜线。
- 全国路线页显示36条路线，支持地区、城市、兴趣、时段与关键词组合筛选；单城显示3条。详情返回保留原筛选，切换到不相容地区时清除原目的地。
- 独立 `footprints.html` 展示已探索城市、不同地点、完成行程、日夜双章城市；支持全部／已探索／单城筛选、展开地点与行程、重看行程及双面卡。
- 首页“我的足迹”和主导航进入全局总览；详情与纪念卡另提供本城足迹。查看记录不增加完成数，不创建日期；同城日夜章齐全才解锁该城双面卡。
- 偏好页未选城市时显示“请选择城市”，选定后提交。详情或纪念卡没有有效路线时显示选择／未找到行程状态，不自动展示其他城市的行程。
- 新页面与统计直接使用现有 v2 本地记录，不新增存储版本；v1迁移规则、原武汉 ID、住宿隔离和时长兼容保留。2026-10-27 按后续发布要求将已验收的 1.6 同步至现有 GitHub Pages，发布操作不递增代码版本。

## 保留的十二城内容（1.5 起）

- **12 城、36 条路线、108 套时段行程**：武汉、北京、上海、西安、成都、杭州、重庆、南京、广州、苏州、厦门、长沙。
- 每城自然、城市、美食各一条主题路线，分别提供日间四节点、夜间四节点、完整一日六节点；共 202 个具名地点记录、72 家虚构住宿与 36 个合作体验示例。
- 首页增加十二城摄影卡片、地区筛选、中文及拼音搜索；景点名称可定位到对应城市路线。一个关键词可命中多个城市，例如杭州西湖与南京小西湖。
- 偏好页按城市、时段、兴趣选择；导航随时可切城，保留时段与兴趣。路线页支持关键词与兴趣叠加筛选、无结果提示和清除筛选。
- 详情保留预算分项、四项出发自查与调整建议，新增起终点和交通说明、可展开的官方资料来源。
- 日夜纪念章按城市分别收集；同城日夜章齐全才解锁该城双面卡。直接访问完成页只预览，重复完成不增加不同地点数。
- 新增 44 张本地授权摄影，加上原武汉的四类摄影，每城均有自然、街区、美食与夜景图片。摄影为同城主题参考，不代表每个节点逐点实拍。

日夜行程分别编排：例如颐和园主题夜线为什刹海湖岸，南山主题夜线为南滨路，鼓浪屿主题夜线为本岛鹭江道。标题、起终点和交通会随时段变化，不默认园林、山地或场馆夜间开放。

## 启动

无需框架、安装或构建。

- 可直接双击 `index.html`，或使用 VS Code Live Server。
- 推荐在本目录运行 `node tools/serve.js`，打开 `http://127.0.0.1:4173`；Ctrl+C 停止。
- 也可使用 `python -m http.server 4173 --bind 127.0.0.1`。

网页运行只读取本地脚本、样式和图片，不请求推荐、天气、地图或票务服务。根目录入口和相对路径兼容 GitHub Pages 项目子路径。

线上访问：[拾光微旅](https://fanshou46-rgb.github.io/micro-travel/)。不同地址的本地记录各自保存，电脑文件预览中的足迹不会自动转移到线上地址。

## 六页流程

| 页面 | 体验 |
| --- | --- |
| `index.html` | 跨城市日夜故事、十二城发现、全国精选／城市榜及全局足迹总览 |
| `choose.html` | 同页选择城市、日间／夜间／一日、自然／城市／美食 |
| `routes.html` | 全国或单城路线、地区／城市／兴趣／时段／关键词组合筛选、预算比较 |
| `detail.html` | 起终点、交通、预算、独立时间轴、出发自查、示例体验与延住计划 |
| `finish.html` | 当前城市完成状态、住宿回显、日夜纪念章及同城双面卡 |
| `footprints.html` | 个人旅行护照、跨城汇总、按城记录、已完成行程及各城纪念章 |

轮播每六秒切换，可手动前后切换与暂停；悬停、聚焦和页面隐藏时自动暂停。系统减少动画模式下只手动切换。外观开关同时更新首页三张故事的摄影、文案与入口，不改写已选旅行时段或本地记录；进入某张故事时，按该故事指定的城市、兴趣与时段开始规划。其他页面切换外观仍只改变皮肤，重新选择时段后恢复自动配色。

## URL 与旧记录兼容

示例：`detail.html?city=hangzhou&route=hangzhou-city&period=night&style=city`。

- `city` 使用城市拼音 ID；缺失或无效时全国浏览，不默认武汉。首页始终全国视角，首页链接中的旧 `city` 不限制内容；足迹页的 `city` 仅用于个人记录筛选。`period=day|night|full`，无效值默认完整一日。
- 原武汉路线 `donghu`、`jianghan`、`wuhan-food` 及原地点和住宿 ID 保留；旧 `duration=half` 映射日间，`duration=day` 映射完整一日。有 `period` 时优先使用它。
- 详情和完成页以有效路线的所属城市为准；路线缺失或无效时显示空态，原武汉有效路线链接继续可用。`region`、`filter`、`q` 保存路线页筛选，详情的 `returnTo` 仅允许返回本站路线列表。
- 切城保留时段与兴趣，清除路线和搜索词；在详情或完成页切城会进入目标城市路线列表。
- 本地记录键为 `daytrip.exploration.v2`。首次发现旧 `daytrip.exploration.v1` 时迁移武汉地点、纪念章、完成记录和住宿；旧键保留，已有 v2 时不再重放迁移。
- 地点全局去重、纪念章按城市隔离、住宿按路线与时段隔离。外观偏好仍使用 `daytrip.appearance.v1`。
- 不同浏览器或站点地址的记录独立。禁用存储或容量不足时保留当前页内存状态，刷新及跨页保存可能不可用。HTTP 预览更适合完整记录演示。

## 文件与维护

- `js/data.js`：公共数据入口、版本及原武汉数据。
- `js/cities/catalog.js`：城市目录、数据注册与共同展示字段；其他城市脚本保存各自手工编写的行程，HTML 按固定顺序加载。
- `js/experience.js`：城市解析、旧记录迁移、打卡与住宿状态。
- `js/main.js`：六页入口、日夜外观、单城行程与住宿交互。
- `js/discovery-data.js`、`js/discovery-ui.js`：人工精选、城市榜、全国发现与独立足迹界面；`css/discovery.css` 为配套样式。
- `css/cities.css`：十二城卡片、筛选、城市封面及移动端适配，沿用既有色板。
- `assets/CREDITS.md`、`assets/city-photos.json`：摄影作者、原作、授权及处理信息；`assets/CITY_SOURCES.md` 为城市资料索引。
- `qa/v1.7/`：本轮日夜轮播检查、全流程回归及截图；`qa/v1.6/`、`qa/v1.5/` 等历史资料保留。

新增城市时，补齐目录、三主题独立行程、图片与来源，再明确配置精选和城市榜，加入六页的相同脚本顺序并运行检查。静态检查核对主题、路线归属、时间、预算、住宿、图片及精选地区覆盖。

可选摄影补图工具：`tools/fetch-city-assets.py`，需要 Python 与 Pillow。交付图片已经齐全，启动网页无需运行它；有授权清单时按清单锁定的作品补图，不重新猜选搜索结果。

## 检查与演示

运行 `node tools/check.js`，检查 108 套行程、预算、授权、静态引用、脚本语法、城市上下文、旧记录迁移、打卡去重、纪念章隔离、住宿和存储异常。

安装或配置 Playwright 后，可运行 `node qa/v1.7/hero-check.cjs` 检查首页日夜联动，或运行 `node qa/v1.7/browser-check.cjs` 进行全流程回归，均使用已安装的 Edge。需要通过 `NODE_PATH` 提供 Playwright 包时，指向本机实际安装目录。验收范围和结果见 `TEST_REPORT.md`。

推荐演示：全国首页看六地区精选 → 查看36条路线并组合筛选 → 完成武汉日间与杭州夜间 → 在“我的足迹”看到两城记录且未错误合并双章 → 完成武汉夜间解锁武汉双面卡 → 返回首页仍为全国视角。

## 教学内容边界

景点名称与片区背景参考官方资料；行程时间和预算由人工编排，不是实地验证或实时规划。预算含餐饮、市内交通和弹性体验，不含住宿、购物及往返出发地。

住宿、合作套餐、价格、评价、模拟用户和排名均用于课程展示，没有真实商家合作、订单、付款或全站统计。自查不产生预约，完成按钮记录本浏览器的模拟探索，没有 GPS 验证。实际开放、船班、交通及消费请出发前核实。

历史课程报告仍保存在本地 `reports/`，本轮未修改报告或覆盖原附件。摄影授权独立于代码，详见素材授权文件。
