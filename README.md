# 拾光微旅 · DAYTRIP

**一座城，日夜都有新发现。** 当前版本：**1.4**（本轮由 1.3 统一递增一次）。

导航右侧提供可点击的日夜外观开关，桌面与手机均可直接切换；支持键盘 Space / Enter。手动切换只改变皮肤，不改变路线、旅行时段、住宿与打卡数据，并在本浏览器内记住偏好。明确重新选择旅行时段后，恢复按时段自动配色。

面向年轻人的武汉微旅行课程 UI 原型。保留五页流程，串联日夜灵感、旅行选择、九套行程、住宿延伸和日夜纪念卡。

1.4 对照课程报告补充预算参考、路线适配与出发自查：推荐页可比较适合人群、步行节奏和重点提醒；详情页先看预算分项，再核对开放、预约、返程与天气。预算是人工教学情景估算，含餐饮、市内交通和弹性体验，不含住宿、购物与往返出发地。自查勾选仅在当前页面显示进度，不产生真实预约。

同步修订的课程报告和修改说明保存在本地 `reports/`，不进入公开网页仓库；原微信附件未覆盖。线上网页沿用 [GitHub Pages](https://fanshou46-rgb.github.io/micro-travel/)，发布版本可在页面底部查看。

## 启动

HTML5、CSS3、原生 JavaScript，无框架、无安装或构建步骤。

- 直接双击 `index.html`，或使用 VS Code Live Server。
- 已安装 Node.js 时，在本目录运行 `node tools/serve.js`，打开 `http://127.0.0.1:4173`；按 Ctrl+C 停止。
- 也可使用 `python -m http.server 4173 --bind 127.0.0.1`。

所有摄影、脚本和样式均为本地相对路径，不依赖外部接口。仓库根目录保留 `index.html` 与 `.nojekyll`，适合 GitHub Pages 项目子路径托管。

## 页面与功能

| 页面 | 体验 |
| --- | --- |
| `index.html` | 三组图文故事轮播、兴趣入口、景区好评榜、用户探索者榜、个人探索手记、品牌与合作理念 |
| `choose.html` | 日间轻游 / 夜间漫游 / 完整一日，加上自然 / 城市 / 美食三种兴趣；夜间选项联动深蓝暖金皮肤 |
| `routes.html` | 所选兴趣优先展示、兴趣筛选、时段切换及对应行程入口 |
| `detail.html` | 独立时间轴、注意事项、模拟景区体验套餐、两家示例住宿与可取消延住计划 |
| `finish.html` | 模拟完成状态、路线与住宿回显、日光章 / 夜游章、武汉日夜双面纪念卡 |

首页轮播每六秒切换；提供前后切换与暂停，悬停、聚焦、页面隐藏时自动暂停；减少动画模式下使用手动切换。图片轮换不会自动改变已选择的旅行时段。

三条路线保留 `donghu`、`jianghan`、`wuhan-food` ID。每条路线拥有日间、夜间、完整一日三套不同安排，日间与夜间各四个节点，完整一日六个节点。

## 推荐演示顺序

1. 首页选择日间故事，选择兴趣并查看路线。
2. 在行程后查看示例住宿，加入延住计划；可查看另一家住宿或取消计划。
3. 点击“完成今日旅行，领取纪念卡”，看到日光章、所选住宿和不同地点数量。
4. 点击“探索夜色”，完成另一段夜游，获得夜游章与日夜双面纪念卡。
5. 返回首页切换两个榜单，展开前五名，打开模拟用户手记与自己的探索记录。
6. 重复完成同一路线，确认不同地点数量保持不变。

完成按钮才会记录模拟探索；直接打开完成页不会增加数量或发放纪念章。日间和完整一日发日光章，夜间发夜游章。按不同地点去重，重复路线与跨时段重叠地点不累计。

## 数据与兼容

新链接示例：`detail.html?route=jianghan&period=night&style=city`。

- `period=day|night|full`；缺失或无效时默认完整一日。
- 旧链接 `duration=half` 映射日间，`duration=day` 映射完整一日。
- 存在 `period` 时优先使用它，无效值回退完整一日；无效兴趣、路线回退默认内容。
- 本地演示记录保存于浏览器 `localStorage` 的 `daytrip.exploration.v1`；住宿选择按路线和时段隔离。
- 手动外观偏好单独保存在 `daytrip.appearance.v1`，不与旅行数据混用；浏览器禁用存储时仍可在当前页面切换。
- 不同浏览器或不同网址的记录相互独立；清除站点数据后会重置。禁用存储时仍能浏览，不承诺跨页保存。

## 教学演示与商业模式

展示三类潜在合作方式：景区及本地体验导流、酒店民宿预订导流、合作展示位。合作内容明确标注，榜单独立排序。

六家住宿、套餐、示例价格、房态、评分与模拟用户均为教学内容；没有真实商家合作、交易或全站用户统计。加入延住计划不会预订或付款。本地模拟完成没有 GPS 验证，夜间安排及开放情况须以实际信息为准。

摄影为有来源的授权素材。首页山湖、森林与住宿空间为通用氛围图；武汉夜景也不代表每个行程节点实拍。详见 [素材授权](assets/CREDITS.md)。

实际浏览器验收与范围见 [TEST_REPORT.md](TEST_REPORT.md)，本轮证据位于 `qa/v1.4/`。旧版证据保留历史品牌与版本。
